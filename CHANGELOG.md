# Changelog

## 1.0.0 — 2026-11-07

- Windows WPF theme controller with enable/disable, connection status, asset validation, and diagnostics.
- Chinese and English interface with a portable language preference.
- Deep Dive theme integration, preserving upstream attribution and MIT notices.
- Local-only connection and target validation, reversible theme operations, and layout-shift rollback.
- Sidebar and title-menu styling; reduced quota scanning and overly broad CSS matching.
- Source build, isolated backend checks, theme regression tests, and a portable Windows ZIP.
